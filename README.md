# RayNeo Workspace v0.8

在 M2 MacBook Air 上，用 USB-C 直连雷鸟 GT，将三个独立 macOS 虚拟桌面显示在眼镜中，并随转头查看。

当前版本已在用户的 M2 MacBook Air、macOS 26.6.2、雷鸟 GT 上验证：三块独立桌面、头部追踪、原生鼠标跨屏、应用窗口拖拽和正常操作可用。其他设备和系统版本尚未验证。

## 使用

1. GT 用支持视频传输的 USB-C 线直连 Mac；本次验证中需要断开占用原生外屏输出的外接显示器。
2. GT 切到“跟随模式”。启动应用时保持眼镜静止约 2 秒，用于估计传感器零偏。
3. 打开 `RayNeoWorkspace.app`，点击 Mac 控制面板的“启动三屏”。
4. 在系统设置中允许 RayNeo Workspace 的屏幕录制权限；如果 macOS 要求，退出并重新打开应用，再启动三屏。
5. 鼠标从 Mac 右边缘依次进入 Left、Center、Right，直接点击、输入、滚动、拖动窗口。无需鼠标模式切换。
6. 转头查看左右桌面；用 Mac 控制面板“回中”校正朝向。“屏幕放大/缩小”调整观看大小。
7. 用“停止三屏”释放虚拟显示器，用“退出”关闭应用并停止 IMU 流。关闭控制面板窗口不等于退出，可以从菜单栏“GT 三屏”重新打开。

启动时每块桌面会放一个可编辑测试窗口，可以关闭后换成自己的应用。

## 可选的窗口移动

先选中目标应用窗口：

- `⌘⌥1`：移到左屏。
- `⌘⌥2`：移到中屏。
- `⌘⌥3`：移到右屏。
- `⌘⌥0`：移回 Mac。

控制面板也有对应按钮，会移动最近选中的其他应用窗口。这些功能需要辅助功能权限；普通鼠标操作不需要。全屏应用需要先退出全屏。

## 构建源码

需要 macOS 与 Xcode 或提供 macOS SDK、Swift 编译器的开发工具。

```sh
bash build.sh
open build/RayNeoWorkspace.app
```

源码入口：`Sources/WorkspaceDemo.swift`。
虚拟显示器接口声明：`Sources/VirtualDisplayBridge.h`。
诊断探针源码：`probes/`。这些探针不是日常使用的必需步骤。

应用包是当前已验证的 Apple Silicon 本机构建，使用临时签名，未做 Developer ID 公证。重新编译和签名会改变身份，macOS 可能需要重新授权屏幕录制。不要在授权和验证之间重新编译当前应用。

## 实现与限制

- 三个 1920×1080 虚拟屏，模式 60 Hz；捕获上限 30 帧/秒，空间场景目标 60 帧/秒。
- 排列为 Mac → Left → Center → Right → GT 实体输出。GT 只负责显示合成场景，不接管鼠标事件。
- 使用私有 `CGVirtualDisplay` 接口，系统升级可能影响兼容性。
- 目前主要跟踪水平转头；长时间陀螺仪漂移可用“回中”修正。
- 不修改眼镜固件或永久配置，仅发送运行时 IMU 开/关指令。
- 只捕获三个虚拟桌面，不捕获音频，不保存录屏，不包含网络上传代码。
- `build/runtime-status.json` 仅用于本地状态诊断，不包含屏幕图像；发布压缩包不包含该运行文件。
- 退出/停止时恢复 GT 输出屏原会话位置。异常退出、热拔插和长时间运行仍需进一步测试。

更多验证历史与协议参考见 `DEVELOPMENT_NOTES.md`。
