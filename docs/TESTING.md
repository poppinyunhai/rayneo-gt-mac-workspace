## 边界

超时后本地清理有上限，但不能保证卡住的系统服务同步停止。强制退出不会执行正常流程；恢复记录只保存 GT 原位置，不承诺恢复所有应用窗口内容。稳定签名不等于公证或 TCC 实机授权验证。功耗和端到端延迟尚未测量，静止修正不提供绝对 yaw。
