## 实机步骤

先退出 v0.8；保留原应用包。不要同时运行两个版本，因为它们使用相同的虚拟屏序列号与同一 GT。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 正常三屏 | 启动开发版，授权，启动三屏 | 三个真实桌面可见；头追和原生跨屏、输入、拖拽可用 |
| 启动期间取消 | 点启动后立即点停止；分别在前 1 秒与捕获建立阶段重复 | 无残留虚拟屏；不会随后重新显示三屏；清理结束后可再启动 |
| 重复停止 | 运行时连续点停止或菜单停止 | 一次清理；结束前不能开始新会话；结束后能重新启动 |
| 启动期间退出 | 点启动后立即 `⌘Q` | 应用待清理结束再退出；不遗留虚拟屏 |
| 清理期间退出 | 运行后点停止，再立即退出 | 不重复停止捕获；清理完成再退出 |
| 连续会话 | 至少 10 次启动/停止 | 无旧错误覆盖新状态、无残留显示器；观察内存是否持续增长 |
| 布局恢复 | 启动前记录系统显示器排列，停止后比较 | GT 恢复原会话位置，Mac 与其他实体屏不被移动 |
| 窗口移动 | 原生拖拽；可选快捷键移到左中右和 Mac | 原生操作保持可用；辅助功能只影响可选移动 |
| 图标 | 查看 Finder、Dock 的开发版 | 显示三屏图标 |
| 权限隔离 | 查看系统屏幕录制列表 | 开发版单独授权，原 v0.8 身份保留 |

异常捕获会触发清理并提示重新启动。设备拔插和睡眠恢复尚未实现完整恢复流程，可作为后续缺陷记录，不作为当前已支持功能。

当前等待系统异步捕获操作结束没有超时兜底。若系统调用长期不返回，退出可能等待；记录发生阶段和系统日志，后续再设计可观测的恢复方案。强制退出不会执行正常清理，不能据此宣称已覆盖异常退出恢复。
