# RayNeo Workspace 0.10.1 朋友体验版

这是独立源码包，包含源代码、图标、构建脚本和测试，不包含已经编译的应用、本机证书私钥或使用记录。

当前用户已确认眼镜三屏、转头查看和 Dock 重新显示控制面板正常。长期运行、拔插和睡眠唤醒仍在试用验证中。

## 环境与构建

需要 Apple Silicon Mac、macOS 26.0 或更高版本、支持当前 macOS SDK 的 Xcode Command Line Tools，以及雷鸟 GT。当前实测环境为 M2 MacBook Air + macOS 26.6.2 + GT，其他设备组合尚未验证。

1. 将整个源码文件夹解压到固定位置，建议路径不含中文或空格。
2. 若没有编译工具，在终端运行 `xcode-select --install`，按系统提示完成安装。
3. 双击文件夹内的 `构建体验版.command`，或在该文件夹打开终端运行：

   ```sh
   SIGNING_IDENTITY=- bash build.sh
   open build/dev/RayNeoWorkspace-Dev.app
   ```

双击脚本只负责构建，完成后到 `build/dev/` 双击应用。若系统不允许执行脚本，使用上面的终端命令即可。构建使用你电脑本地生成的临时签名，不需要原作者的证书或私钥。不要频繁重新构建、移动应用或改变签名，以免屏幕录制权限需要重新授权。长期开发可阅读 `docs/SIGNING.md` 配置自己的固定签名。

## 第一次体验

1. 退出其他 RayNeo Workspace 版本；不要同时运行两套。GT 使用跟随模式，以支持视频的 USB-C 线直连 Mac。当前实测环境没有连接其他实体外屏。
2. 打开应用，点击“启动三屏”。按系统提示在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”允许该应用。若系统要求，退出后重新打开，再点击启动。
3. 保持眼镜静止约 3 秒，等控制面板显示“姿态追踪”，再左右转头查看三个桌面。正前方通常显示中间桌面，左右桌面通过转头查看。
4. 从 Mac 屏幕右边缘移动鼠标，依次进入左、中、右桌面，可以正常输入、滚动和拖动窗口。普通输入不需要辅助功能权限；可选“移动窗口”按钮需要该权限。
5. 朝向偏移时点“回中”。控制面板关闭或最小化后，点击 Dock 图标重开；也可用应用菜单“显示控制面板”或 ⌘0。
6. 使用“停止三屏”恢复桌面布局；退出时用应用里的“退出”或 ⌘Q。

应用不会录制音频或保存屏幕视频，不会上传屏幕内容。运行时在你电脑的 `~/Library/Application Support/RayNeoWorkspace-Dev/` 保存设置、待恢复布局和本地状态诊断。

## 遇到问题

- 只有中间画面且转头不切换：检查控制面板是否显示“姿态追踪”；若还在校准，保持静止约 3 秒。也检查转头轴、方向设置与 GT 跟随模式。
- 黑屏或捕获失败：检查屏幕录制权限，按提示退出重开；可以切换“兼容模式 · Core Image”，停止后重新启动。
- 拔插后未恢复：点击停止，再重新启动。异常退出后重新打开，必要时点击“恢复布局”。
- 反馈时提供 Mac 型号、macOS 版本、GT 型号、复现步骤和控制面板状态即可。不要把个人屏幕内容或私钥一起发出。
